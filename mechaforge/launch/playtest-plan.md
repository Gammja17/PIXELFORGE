# 외부 플레이테스트 계획 (itch.io 무료 데모)

출시 준비 보고서의 2단계(G1 관문)를 위한 실행 문서다.

## 기능 동결
- 이 문서를 만든 시점부터 **새 기능, 새 콘텐츠는 넣지 않는다.**
- 고치는 것은 세 종류만: 플레이테스트에서 나온 문제, 오류, 출시 필수 항목(크레딧, 저장, 기록).
- 예외가 필요하면 이 파일에 이유를 적고 넣는다.

## 목표 (G1 관문)
| 지표 | 목표 | 어떻게 재나 |
| --- | --- | --- |
| 테스터 수 | 30명 이상 | 설문 응답 수 |
| 첫 판을 끝까지(승리 또는 사망) 한 비율 | 70% 이상 | 게임 안 기록(`테스트 기록 복사`) |
| 스스로 두 번째 판을 시작한 비율 | 50% 이상 | 게임 안 기록의 판 수 |
| 첫 3분 안에 그만둔 비율 | 20% 이하 | 게임 안 기록의 판 길이 |
| "다시 하고 싶다" 4~5점 | 50% 이상 | 설문 Q4 |

넘으면 3단계(웹 포털), 못 넘으면 이탈 지점을 고치고 다시 잰다.

## 진행
1. itch.io에 HTML 게임으로 올린다(`dist/mecha.html` 하나). 공개 범위는 처음엔 '링크가 있는 사람만'.
2. 테스터를 모은다: 지인 10명, 국내 인디 게임 커뮤니티/디스코드 20명 이상. 처음 하는 사람을 우선한다.
3. 테스터에게 주는 안내(아래 문구 그대로):
   > 설명 없이 그냥 해 주세요. 그만하고 싶어지면 언제든 그만두셔도 됩니다.
   > 끝나면 결과 화면의 '테스트 기록 복사'를 누르고, 설문에 붙여넣어 주세요.
4. 가능하면 3~5명은 화면 공유로 지켜본다(말없이). 어디서 멈칫하는지 적는다.
5. 1주 뒤 집계 → 보고서 체크리스트 갱신.

## 직접 해야 하는 것 (계정이 필요)
- itch.io 계정과 페이지 만들기: 문구는 `itch-page.md`
- 설문 만들기(Google Forms 등): 문항은 `survey.md`. 만든 뒤 설문 URL을 게임 안 설문 링크 상수에 넣고 다시 빌드
- 실제 기기 성능 측정: 저사양 노트북, 안드로이드 폰, 아이폰 각 1대에서 `?bench=1`
- 15초 GIF: 시작 기체 → 후반 거대 기체가 보이게
