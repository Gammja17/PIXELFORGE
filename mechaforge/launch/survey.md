# 플레이테스트 설문 (5문항 + 기록)

짧게 유지한다. 길면 응답률이 떨어진다.

1. **얼마나 하셨나요?** (객관식) 첫 판 도중에 그만둠 / 첫 판 끝까지 / 2판 / 3판 이상
2. **그만둔(또는 끝낸) 이유는?** (객관식 + 기타) 어려워서 / 지루해서 / 뭘 해야 할지 몰라서 / 화면이 복잡해서 / 버그·느려서 / 다 해서 / 기타
3. **가장 재미있었던 순간 하나는?** (주관식, 한 줄)
4. **다시 하고 싶은 정도는?** (1~5)
5. **가장 헷갈리거나 짜증났던 것 하나는?** (주관식, 한 줄)
6. **테스트 기록 붙여넣기** (긴 주관식, 선택) 결과 화면의 '테스트 기록 복사' 내용

기기 정보(PC/폰, 브라우저)는 기록에 들어가므로 따로 묻지 않는다.
