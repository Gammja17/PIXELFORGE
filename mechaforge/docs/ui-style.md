# MechaForge UI 스타일 가이드

새 화면이나 HUD를 고칠 때 이 문서를 먼저 따른다. 어긋나는 게 필요하면 이 문서부터 고친다.
(배경: 두 세션이 같은 HUD를 각자 다시 만들어 충돌한 적이 있다. 화면마다 담당은 하나만 둔다.)

## 1. 화면 배치
- 화면 가운데는 기체 자리다. 패널, 배너, 팁, 튜토리얼은 가운데 40% 원 안에 두지 않는다.
- 전투 HUD 자리는 고정이다.
  - 왼쪽 위: 레벨, 경험치, 체력
  - 가운데 위: 구역/방 정보, 보스 체력
  - 오른쪽 위: 처치 수, 일시정지
  - 아래쪽 줄: 무기 슬롯, 스킬 슬롯
- 알림 순서(위에서 아래로): 배너(HUD 바로 밑) → 문 표지 → … 기체 … → 팁/튜토리얼/알림(아래 줄 바로 위).
- 같은 순간에 화면에 뜨는 글 상자는 최대 2개다. 더 생기면 줄을 세운다(팁 큐처럼).

## 2. 글자
- 글꼴은 Galmuri 하나. 크기는 **12px 배수(12 / 24 / 36 / 48)만** 쓴다. 도트 글꼴이라 그 밖의 크기는 번진다.
- 본문 12, 이름·숫자 강조 24, 화면 제목·카드 이름 24~36, 컷인 48.
- 한 줄 안내는 15자 안팎. 긴 설명은 카드/설명 칸에만 둔다.
- 숫자(체력, 쿨타임, 가격)는 늘 글자로 함께 보여 준다. 막대만으로 전달하지 않는다.

## 3. 색: 뜻이 정해져 있다
| 토큰 | 뜻 | 쓰지 말 곳 |
| --- | --- | --- |
| `--accent` 호박 | 선택됨, 주 버튼(출격), 무기 | 경고 |
| `--hp` 빨강 | 내 체력, 위험, **적 공격** | 내 무기/이펙트 |
| `--pink` 자홍 | 특수기, 보스, 적 공격 보조 | 내 기본 공격 |
| `--cyan` 청록 | 대시, 몸통 부품(모듈), 정보 팁 | 위험 |
| `--xp` 초록 | 경험치, 회복, 강화(▲) | |
| `--od` 주황 | 오버드라이브 | 다른 것 |
- 적 공격은 빨강/자홍만 쓴다. 내 무기 색과 겹치면 안 된다.
- 한 화면에서 깜빡이는(애니메이션) 강조는 하나만. 둘 이상이면 아무것도 안 보인다.

## 4. 판(패널)
- 기본 판: 어두운 반투명 배경(`rgba(9, 11, 17, .88)`) + 1px 테두리(`#3a4158`) + 1px 검은 외곽. 격납고 v8 판이 기준이다.
- 두꺼운 철판(`.pix`, 12px border-image)은 **모달 창과 경고 배너에만** 쓴다. HUD에는 쓰지 않는다.
  - 현재 전투 HUD 일부(`#hpbox`, `#roombox`, `#kills`, `#toast` 등)는 아직 `.pix`를 쓴다. 다음 HUD 손질 때 기본 판으로 맞출 대상이다.
- 선택 상태: 호박 테두리 + 아래 3px 호박 줄. 잠김: 점선 테두리, 실루엣은 형태가 보일 만큼 밝게.

## 5. 크기와 배율
- 기준 화면은 800x450 논리 픽셀이다. 큰 화면은 `--uiz`(최대 1.8)로 키우고, 격납고는 `--hz`로 더 적게 키운다.
- zoom이 걸린 요소에 화면 px 값을 넣을 때는 uiz로 나눈다(`tutorial.js`의 `px()` 참고).
- 확인할 해상도는 800x450, 1600x900, 1920x1080, 폰 가로(844x390) 네 가지. 넷 다 스크린샷을 찍어 본다.

## 6. 키 안내
- 키는 `kbd.k` 칸으로 보여 준다. 터치 기기에서는 숨긴다(`.ui-touch`).
- 기능은 쓸 수 있게 되는 순간에 키와 함께 한 번 알려 준다. 늘 떠 있는 조작 안내줄은 두지 않는다.
