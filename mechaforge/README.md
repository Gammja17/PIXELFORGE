# MechaForge (PixelForge 엔진 메카 로그라이크)

하데스식 직접 조작 전투 + 뱀서식 물량전. 고철을 주워 부품을 붙이며 기체가 점점 거대해진다.

**웹에서 바로 하기: https://gammja17.github.io/PIXELFORGE/mechaforge/dist/mecha.html**

## 실행 / 빌드
- `dist/mecha.html` 더블클릭 (단일 파일, 사운드 포함)
- `node tools/pack-audio.mjs` (사운드 에셋을 바꿨을 때만) → `node build.mjs`
  - `dist/mecha.html`, `dist/mecha.artifact.html`(아티팩트용), `index.html`(개발용)
  - node 가 없으면 `powershell -File build.ps1` (같은 결과물)

## 조작
| | 데스크톱 | 폰 (가로) |
|---|---|---|
| 이동 | WASD | 왼쪽 드래그 |
| 공격 (콤보/연사) | J, 마우스 왼쪽 | 공격 버튼 (자동 조준) |
| 특수기 | K, 마우스 오른쪽 | 특수 버튼 |
| 대시 | Space, Shift | 대시 버튼 |
| 오버드라이브 | L, Q | 게이지가 차면 나타나는 버튼 |
| 변형 모드 | E, Tab | 초록 변형 버튼 |
| 기타 | Esc/P 일시정지, `[` `]` 도트 크기, Enter 출격 | |

## 한 판의 흐름
1. 격납고: 머리, 프레임, 다리, 주무장, 도색 선택. 고철로 잠긴 부품 해금, 연구(영구 강화).
2. 방마다 제한 시간 동안 떼로 몰려오는 적을 버팀 → 시간이 끝나면 남은 적이 줄줄이 폭파 → 보상 → 출구 문 선택.
3. 3번째 방, 6번째 방: 구역 수호자 (샌드웜, 크레인 워커). 부위를 부숴야 본체가 약해진다.
4. 마지막 방: 타이탄.
5. 결과: 고철 획득 → 격납고에서 사용.

## 핵심 시스템
- **물량전**: 고철 벌레(떼), 자폭 드론, 정찰 드론, 경전차, 중장 메카. 정예는 부품 상자를 떨어뜨림.
- **연쇄 폭발**: 자폭 드론 폭발 + 연쇄 기폭 장치(시스템 업그레이드).
- **무기 진화**: 최대 레벨 무기 + 맞는 몸통 부품 → 진화 카드 (개틀링 포대, 드래곤 브레스, 스웜 미사일, 하이퍼 메가 빔, 광자 대검, 판넬 폭풍).
- **커지는 기체**: 레벨마다 크기, 체력, 화력 증가. 오버드라이브 중엔 더 커짐.
- **변형 모드**: 보행 / 비행(빠름, 지상 적 접촉 무시) / 저격(피해, 치명, 사거리, 관통 증가, 느림, 조준선) / 섬멸(자동 난사, 연사, 범위 증가, 받는 피해 증가).
- **부품 노획**: 경전차는 전차 포신(어깨 자동 포), 중장 메카는 스파이크 견갑, 정예 드론은 판넬 비트, 크레인 워커 팔은 미사일 포드와 스파이크 견갑을 떨어뜨림. 바닥의 실제 부품에 다가가면 날아와서 장착.
- **연출**: 연속 처치 카운터, 대량 처치 슬로모션, 진화/오버드라이브 컷인, 드론 장착 연출.

## 구조 (`game/`)
| 파일 | 역할 |
|---|---|
| `ui.js` | 진입점. HUD, 격납고(탭, 해금, 연구), 카드, 결과, 터치 버튼, 컷인, 콤보 표시 |
| `main.js` | 상태 머신, 카메라, 콤보/슬로모, 음악 전환, `game.debug` |
| `rooms.js` | 방 생성, 물량 스폰(stream/surge), 수호자/보스 방, 문 |
| `enemies.js` | 적 종류, AI, 연쇄 폭발(blast), 타이탄 |
| `guardians.js` | 구역 수호자 2종 + 부위 파괴 |
| `weapons.js` | 무기, 진화(`EVOLUTIONS`), 직접 조작 콤보, 특수기 |
| `player.js` | 능력치, 성장(크기), 오버드라이브, 비상 재기동 |
| `upgrades.js` | 카드 뽑기/적용 (진화 포함) |
| `meta.js` | 고철, 해금 가격, 연구 |
| `sound.js` + `audio-data.js` | WebAudio 재생 (자동 생성된 에셋 묶음) |
| `install.js` | 드론 장착 연출 |
| `skin.js` | 도트 강철 판넬 UI 텍스처 생성 |
| `parts.js`, `icons.js`, `fx.js`, `pickups.js` | 부품 모델, 아이콘, 이펙트, 드롭 |
