# MechaForge (PixelForge 엔진 메카 로그라이크)

하데스식 직접 조작 전투 + 뱀서식 물량전. 고철을 주워 부품을 붙이며 기체가 점점 거대해진다.

**웹에서 바로 하기: https://gammja17.github.io/PIXELFORGE/mechaforge/dist/mecha.html**

## 실행 / 빌드
- `dist/mecha.html` 더블클릭 (단일 파일, 사운드 포함)
- `node tools/pack-audio.mjs` (사운드 에셋을 바꿨을 때만) → `node build.mjs`
  - `dist/mecha.html`, `dist/mecha.artifact.html`(아티팩트용), `index.html`(개발용)
  - node 가 없으면 `powershell -File build.ps1` (같은 결과물)

## 한 판의 흐름
1. 격납고: 머리, 프레임, 다리, 주무장, 도색 선택. 고철로 잠긴 부품 해금, 연구(영구 강화).
2. 방마다 제한 시간 동안 떼로 몰려오는 적을 버팀 → 시간이 끝나면 남은 적이 줄줄이 폭파 → 보상 → 출구 문 선택.
3. 3번째 방, 6번째 방: 구역 수호자. 구역이 계열을 정하고(땅 파는 계열: 샌드웜 또는 거미 전차, 거대 기계 계열: 크레인 워커 또는 히드라 포대) 런마다 원판/변종 중 하나가 나온다. 부위를 부숴야 본체가 약해진다.
4. 마지막 방: 타이탄. 한 번 쓰러뜨리면 다리가 터져 나가고 비행 코어 MK-II 로 재기동한다.
5. 결과: 고철 획득, 무기별 초당 피해, 새 업적 → 격납고에서 사용.

## 반복 플레이
- **위협 등급**: 첫 타이탄 격파 후 열림. 적 체력/피해/물량, 중간 보스 증원, 보급 차단 등 8가지를 단계별로 켜면 위협 점수만큼 고철 +10%씩. 최고 격파 위협은 격납고에 표시.
- **파일럿**: 장점 하나 + 단점 하나. 신참 레오 외 4명은 업적으로 합류.
- **업적**: 17개. 파일럿, 업적 전용 도색, 부품(이미 샀으면 고철 환급)을 준다. 격납고 `업적` 버튼으로 목록.

## 핵심 시스템
- **물량전**: 고철 벌레(떼), 자폭 드론, 정찰 드론, 경전차, 중장 메카. 정예는 부품 상자를 떨어뜨림. 역할 기체: 저격, 방패(옆/뒤를 칠 것), 그림자 암살, 분열, 수리 드론(먼저 잡을 것), 지뢰 부설, 돌격.
- **난이도 곡선**: 첫 전투 방은 무쌍 (벌레, 드론, 자폭 드론뿐. 피해 약하고 경험치 1.5배, 중간 보스 없음) → 첫 수호자는 가볍게 → 깊이 3 첫 중간 보스, 깊이 3~4 에 역할 기체와 정예 특성이 하나씩 → 깊이 6 부터 전부 + 탄막 최대 → 타이탄이 가장 높은 벽. 초반엔 빨리 강해져도 적이 거의 따라오지 않고, 깊을수록 전력 보정이 세진다. 깊이별 물량/피해/체력/중간 보스/등장 적 표는 `rooms.js` 의 `CURVE` 주석.
- **연쇄 폭발**: 자폭 드론 폭발 + 연쇄 기폭 장치(시스템 업그레이드).
- **무기 진화**: 최대 레벨 무기 + 맞는 몸통 부품 → 진화 카드 (개틀링 포대, 드래곤 브레스, 스웜 미사일, 하이퍼 메가 빔, 광자 대검, 판넬 폭풍).
- **커지는 기체**: 레벨마다 크기, 체력, 화력 증가. 오버드라이브 중엔 더 커짐.
- **변형 모드**: 보행 / 비행(빠름, 지상 적 접촉 무시) / 저격(피해, 치명, 사거리, 관통 증가, 느림, 조준선) / 섬멸(자동 난사, 연사, 범위 증가, 받는 피해 증가).
- **부품 노획**: 경전차는 전차 포신(어깨 자동 포), 중장 메카는 스파이크 견갑, 정예 드론은 판넬 비트, 크레인 워커 팔은 미사일 포드와 스파이크 견갑을 떨어뜨림. 바닥의 실제 부품에 다가가면 날아와서 장착.
- **연출**: 연속 처치 카운터, 대량 처치 슬로모션, 진화/오버드라이브 컷인, 드론 장착 연출.
- **구역 / 지형**: 6개 구역(사막 폐허, 폐공장, 수정 협곡, 용암 주조소, 동토 설원, 궤도 정거장) 중 런마다 3곳을 섞어서 고른다. 방마다 배치(열주, 십자 회랑, 원형 투기장, 삼중 통로, 참호, 전선)와 부서지는 엄폐물. 적 탄은 벽과 엄폐물에 막힌다.
- **환경 위험**: 폭발 드럼통(연쇄), 지뢰, 용암 균열, 전기 바닥, 컨베이어, 냉각 분출구, 빙판, 공명 수정탑. 적도 똑같이 다친다. 바닥 위험은 비행 모드면 무시.
- **특수 방**: 정전 구역(기체 조명만), 수축 방어막(고리 밖 피해). 버티면 정비 포인트 +1.

## 구조 (`game/`)
| 파일 | 역할 |
|---|---|
| `ui.js` | 진입점. HUD, 격납고(탭, 해금, 연구), 카드, 결과, 터치 버튼, 컷인, 콤보 표시 |
| `main.js` | 상태 머신, 카메라, 콤보/슬로모, 음악 전환, `game.debug` |
| `rooms.js` | 구역(ZONES), 난이도 곡선(CURVE, FIRST), 런 구역 순서, 방 생성, 물량 스폰(stream/surge), 수호자/보스 방, 문, 충돌(clamp) |
| `world.js` | 방 배치(레이아웃), 구역별 벽/기둥/소품 모양, 적 길찾기 흐름장 |
| `hazards.js` | 환경 위험 요소, 부서지는 소품(enemies 격자에 들어감), 특수 방 |
| `enemies.js` | 적 종류, AI, 연쇄 폭발(blast), 타이탄 (+ MK-II), 정예 특성(발밑 고리 색), 휘는/멈췄다 터지는 탄 |
| `troops.js` | 역할 기체 7종 (저격, 방패, 암살, 분열, 수리, 지뢰, 돌격) 모델 + AI |
| `midbosses.js` | 중간 보스 6종 (나선, 랜서, 하이브, 박격, 분광 수정체, 추적 돌격기) |
| `guardians.js` | 구역 수호자 4종 + 부위 파괴, 구역 계열 안에서 원판/변종 고르기 (pickGuardian) |
| `weapons.js` | 무기, 진화(`EVOLUTIONS`), 직접 조작 콤보, 특수기 |
| `player.js` | 능력치, 성장(크기), 오버드라이브, 비상 재기동 |
| `upgrades.js` | 카드 뽑기/적용 (진화 포함) |
| `meta.js` | 고철, 해금 가격, 연구, 위협 선택/최고 기록, 파일럿, 업적 달성 (저장) |
| `progress.js` | 위협 등급, 파일럿, 업적 정의 + `runMods()` (런 규칙 배율) |
| `runhooks.js` | `game.mods` 를 방/적/회복/능력치에 덧씌우기, 무기별 피해 집계 |
| `sound.js` + `audio-data.js` | WebAudio 재생 (자동 생성된 에셋 묶음) |
| `install.js` | 드론 장착 연출 |
| `skin.js` | 도트 강철 판넬 UI 텍스처 생성 |
| `parts.js`, `icons.js`, `fx.js`, `pickups.js` | 부품 모델, 아이콘, 이펙트, 드롭 |
